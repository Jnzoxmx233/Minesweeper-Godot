# 扫雷 (Minesweeper)

基于 **Godot 4.6** 开发的经典扫雷游戏，支持难度切换与辅助标旗。

## 项目结构

| 文件 | 说明 |
|------|------|
| `main.tscn` | 主场景，定义 UI 层级与节点属性 |
| `main.gd` | 主逻辑脚本，涵盖全部游戏逻辑 |

## 场景节点层级
···
Main (Control) — 全屏根节点  
├── DifficultyMenu (PopupMenu) — 右键菜单（难度/功能）  
│    └── DifficultySubmenu (PopupMenu) — 子菜单（初级/中级/高级）  
└── VBoxContainer — 整体垂直布局（居中）  
    ├── HBoxContainer — 顶部横条（居中）  
    │    ├── MineLabel — 地雷计数 💣  
    │    ├── ResetButton — 重置按钮 😊  
    │    └── TimeLabel — 计时器 ⏱  
    └── Grid (GridContainer) — 网格按钮区（居中）  
        └── 9×9 / 16×16 / 30×16 按钮  
···
## 游戏操作

| 操作 | 效果 |
|------|------|
| **左键** 未揭开格子 | 揭开该格 |
| **左键** 已揭开数字格 | 快速揭露（周围旗数匹配时有效） |
| **右键** 未揭开格子 | 插旗 / 取消插旗 |
| **左键** 笑脸按钮 | 重新开始当前难度 |
| **右键** 笑脸按钮 | 弹出功能菜单 |

## 核心模块说明

### 常量 & 难度预设
定义格子尺寸和三档难度参数（初级 9×9/10雷、中级 16×16/40雷、高级 30×16/99雷）。

### 核心数据（5 张二维网格图）
- `mine_map` — 地雷位置，`0`＝安全，`1`＝地雷
- `number_map` — 数字，`-1`＝地雷，`0~8`＝周围地雷数
- `revealed` — 揭开状态，`true`＝已揭开
- `flagged` — 旗子状态，`true`＝已标旗
- `buttons` — 按钮引用，供 UI 操作

### 布雷与首点保护
- 随机放置地雷
- 第一次点击必定安全：移除 3×3 范围内的地雷并重新分配到远处

### 数字计算
遍历所有安全格，统计每个格子周围 3×3 范围内的地雷数量。

### 交互处理
- **左键**：揭开格子；对已揭开的数字格触发快速揭露
- **右键**：切换旗子标记

### 揭开核心
递归揭开空白区域（DFS）。踩雷时显示所有地雷并结束游戏。

### 快速揭露
当地雷数字周围的旗子数 === 该数字时，自动揭开周围所有未标旗的格子。

### 辅助模式（可开关）
每次点击后扫描所有已揭开的数字格：若该数字周围的**全部未揭开格子数**（含已标旗的）== 该数字，则这些格子必然都是地雷，自动标旗。

### 计时 & 界面更新
首次点击后开始计时，每秒更新显示；实时计算剩余地雷数。

### 调试
每次开局在控制台输出 ASCII 地雷位置图（`*`＝地雷，`.`＝安全）。

## 配置扩展

调整 `DIFFICULTY_PRESETS` 字典即可新增自定义难度：

```gdscript
const DIFFICULTY_PRESETS = {
    "专家 50x30": {"rows": 30, "cols": 50, "mines": 400},
}
```

调整 `CELL_SIZE` 可修改格子像素大小。
